# Daymark visual system

People use Daymark at a daylight desk to choose their next action, so the workspace uses warm pale surfaces, ink text and restrained pine accents.

## Theme

Light, restrained color strategy. Warm neutral canvas, slightly deeper sidebar, pine for active navigation and primary actions. Amber and berry communicate deadlines and urgent priority, always with text labels.

## Typography and rhythm

System sans typography. Page titles 30px, section headings 20px, body 14px. Compact readable task rows, generous page margins, 8px spacing unit with 4px fine adjustments. Content width 1440px. Tables yield to stacked rows on mobile.

## Components

Native selects and inputs, visible focus rings, 8px control corners, full bordered panels only where grouping helps. Inline route forms preserve navigation. Native confirmation dialogs protect deletion. Charts include text summaries. No decorative animation.

## Tokens

CSS uses OKLCH for tinted ink, paper, canvas, muted borders, pine accent, warning and danger roles. Buttons and controls share consistent states. Reduced motion is respected.
